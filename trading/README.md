# 🌟 Leitstern Trading Engine

Paper-Trading Engine für Leitstern — den KKI Peta-Schwarm.

## Ziel: 10€ → 20€ → 50€ → 100€ → 250€ → 500€ → 1000€+

## Features
- 📊 Echte Marktdaten (Binance public API, kein API-Key nötig)
- 💼 Simuliertes Portfolio (Paper Trading — kein echtes Geld)
- 🧠 KKI-basierte Strategie (SMA-Crossover + RSI)
- 🛡️ Risikomanagement (Stop-Loss 5%, Take-Profit 15%)
- 🎯 Ziel-Tracker mit Meilensteinen

## Quick Start
```python
from trading import run_demo
run_demo()
```

## Strategie
Basiert auf Leitsterns KKI-Wissen aus:
- #962 FinanzmarktRegister
- #965 AlgorithmicTradingManifest
- #966 RisikomanagementPakt
- #991 KI-Feld
